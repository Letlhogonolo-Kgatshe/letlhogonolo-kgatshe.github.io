The problem

I was learning data analytics, photography and reading from scattered notes and bookmarks, with no weekly plan and no way to see whether I was keeping up. I wanted one place that tells me what to do today, tracks what I actually did, and works on both my laptop and my phone.

What I built

  • A curriculum in eight-week seasons, with five views: Today, Learn, Reading, Plan and Progress.
  • A 37-milestone path to a junior data analyst job (CV and applications, Excel, Power BI, SQL, statistics, Python, three portfolio projects), ordered by what current Cape Town job listings ask for.
  • Weekly study targets per subject, daily minimums, streaks and a session log, so progress is measured in minutes studied and pages read.
  • A list of upcoming Cape Town events for field trips, loaded from a data file that is refreshed every Monday.

Key decisions

One file, no framework

The whole app is a single HTML file with no dependencies or build step. It loads fast and can be added to a phone home screen.

Progress stays private

Everything is saved in the browser. Sync across devices is opt-in and uses a secret GitHub gist, with a token that only has the gist permission, so there is no server and no account to create.

Content separate from code

Events live in events.json, so they can be refreshed weekly without touching the app.

Results

  • Live on GitHub Pages and in daily use since 29 October 2026.
  • Season 1 runs from 26 October to 20 December 2026.
  • The data path feeds this portfolio: its milestones include the projects and case studies shown here.
